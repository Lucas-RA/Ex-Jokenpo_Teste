# Contexto

- **Objetivo:** exercício didático de Jokenpô (Pedra, Papel e Tesoura) em Flutter para aprender testes (unitários, de widget, TDD, injeção de dependência e Fake), seguindo o tutorial https://www.heiderlopes.com.br/flutter/tutoriais/flutter-testes-jokenpo-com-tdd-v2.
- **Entregáveis:** histórico de commits passo a passo + documentação simplificada no `README.md`.
- **Stack:** Flutter 3.47 / Dart 3.13, `flutter_test`, `flutter_lints`.
- **Pacote Dart:** `jokenpo_teste` (o tutorial usa `jokenpo_tests`; os imports foram adaptados).
- **Arquitetura final:** `lib/models` (enum `Jogada`, `Placar`), `lib/services` (`JokenpoService`, `Player`, `ComputerPlayer`), `lib/screens` (`JokenpoScreen`).
- **Comandos:** `flutter pub get` · `flutter analyze` · `flutter test` · `flutter run`.
- **Remoto:** https://github.com/Lucas-RA/Ex-Jokenpo_Teste (branch `main`).
